# Clubs utilisateurs de Score'n'co repérés sur le web

Recherche du 26/11/2026. Trois niveaux de preuve :
- **Vérifié sur le site** : le code Score'n'co a été trouvé sur le site du club (fichiers MonSiteClub servis par `scorenco.com/wp-content/uploads/sites/…` ou widgets `scorenco.com/widget/…`).
- **Cité par Score'n'co** : le club figure sur une page produit de scorenco.com.
- **Publié par Score'n'co** : le club a fait l'objet d'un post Score'n'co (voir `historique/`).

> Piste pour en trouver d'autres : tous les sites MonSiteClub ont pour titre par défaut « Un site utilisant Mon Site Club » et chargent leurs fichiers depuis `scorenco.com/wp-content/uploads/sites/<N>/`. Les numéros vont au moins jusqu'à 160, ce qui laisse penser qu'il y a 160 sites ou plus. La liste complète est à demander à Score'n'co.
