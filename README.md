# Score'n'co · Pilotage social media

Base de travail du community management de Score'n'co (Facebook, Instagram, LinkedIn, Meta Ads) : sources, historique des publications, analyses et calendriers éditoriaux.

## Contenu

| Dossier | Ce qu'on y trouve |
| --- | --- |
| `sources/` | Index de toutes les sources utilisées : documents Drive (charte, bilans, briefs), sources web des temps forts |
| `historique/` | Export de toutes les publications FB/IG et LinkedIn depuis février 2025 |
| `analyses/` | Analyse éditoriale de l'historique (sports, thèmes, formats) |
| `calendriers/` | Calendriers éditoriaux mensuels, avec leurs choix et leurs points à valider |
| `skills/` | Skill Claude « scorenco-calendrier-editorial », la méthode de construction d'un mois |

## Calendrier en cours

Décembre 2026 – Janvier 2027 : [`calendriers/2026-12_2027-01.md`](calendriers/2026-12_2027-01.md).
La version de travail, modifiable, est le Sheet Claude « Score'n'co – Calendrier éditorial Décembre 2026 & Janvier 2027 ».

## Règles du projet (rappel)

- 5 gabarits de la charte éditoriale, avec un gabarit par contenu.
- Diversité : Football, Basket, Handball, Rugby, Volley, Hockey sur glace, Rink-hockey et Roller-hockey, avec des contenus pour les jeunes, les seniors, les équipes féminines et la vie du club.
- Fact-checking strict : aucun chiffre sans source. Chiffre de référence : plus de 3 000 clubs utilisent les widgets.
- Cadence : 3 posts FB/IG et 2 posts LinkedIn par mois, plus 1 campagne Meta Ads.
